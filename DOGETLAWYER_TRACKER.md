## 4. Series-wide production rules

These rules held across Cases 01–05:

- [ ] **No prices, plans, tiers or offers** anywhere (this also covers P1).
- [ ] **Never imply** payment recovery, debt collection, acting on the customer's behalf, payroll/HMRC filing, or bank/email/calendar sync. The product only holds what a person enters and assigns internal tasks to named people.
- [ ] **No comparative "better than" claims.** The boss's ask to say "we solve it better than anyone" was deliberately **not** written; the films argue through specifics instead.
- [ ] **Every statistic is attributed** on screen and in every description.
- [ ] **All demo data is fictional and British**, labelled in-frame ("DEMO DATA" / "FICTIONAL DEMO EXAMPLE"), with a persistent footer.
- [ ] **The closing card always carries:** "Contract management software for UK small businesses — not a substitute for legal advice." (Case 01 short used "general legal information — not legal advice.")
- [ ] **Legal statements are hedged in-frame:** "GENERAL POSITION — OUTCOMES TURN ON THE FACTS".
- [ ] **Format:** 1080×1920, 9:16, 30 fps, ~1:59 (119.000 s), silent stereo AAC ready for voiceover, captions burned in.
- [ ] **Structure:** hook → problem → UK-wide scale (real statistics) → legal turn → fix → how Dogetlawyer does it → next step → CTA ("Send this to whoever…").
- [ ] **VO delivery:** calm, matter-of-fact, a colleague giving practical advice, never salesy. Each script names one "safe cut" line in case the read runs long.
- [ ] **Each case gets its own ground/palette.** From Case 04 on, each case also gets its own typeface (see §12).
- [ ] **Each case should use a different script category** (boss's request; first applied in Case 05).

**Boss's creative brief (Case 01 long and later):**

- 1:30–2:00 long, never boring.
- Hook → problem → solution → how Dogetlawyer solves it.
- The viewer must recognise their own problem. Show it is a real UK business-wide problem, not just a legal-tech one.
- Use British names for demo data.

**What was declined:** the stated reason for British names included hiding that the product is built by Asian people. The assistant used British names on localisation grounds and **declined to design toward hiding who built the product**. The British-name rule stands; the concealment rationale was not adopted.

## 7. Case File 02 — "The renewal you didn't ask for"

- **Topic:** a business contract auto-renews because nobody tracked the *notice* deadline.
- **Runtime:** 1:59. **Script:** ~296 words at ~150 wpm.
- **Turn (1:07):** "Those rules cover consumer contracts." Beat. "You signed as a company. So nobody has to tell you."
- **Ground:** deep ink-navy `#0C1420` with a faint 7-column calendar grid and one warmer column.
- **Closing card:** "NEVER MISS ANOTHER RENEWAL DEADLINE."
- **Demo data:** Sarah Whitfield, T. Baker, R. Ellis, Brightwater Systems, Calder & Finch, Kirkby Joinery, ref DGL-0207.

### 7.1 VO (clean read)

> You didn't renew it. It renewed itself. The confirmation arrives. Twelve more months of something you'd already decided to drop. Four thousand three hundred and twenty pounds, for a tool your team stopped using in March. You knew the renewal date. You didn't know the notice deadline. They're not the same date — and only one of them mattered. This isn't carelessness. Auto-renewal is a design. It works because you're busy. Nine point seven million unwanted subscription contracts are active in the UK right now. One point six billion pounds a year, spent on subscriptions nobody wants. ## 18. Tooling and environment notes: how the videos were actually made

Source: the full transcript of the video session (`session_01LMgXD1ea85H9xmxkavzVqH`, titled "Dogetlawyer short-form video", 29 Sep 09:48 → 1 Oct 14:22). It's a Claude Cowork session run from the **Claude in Chrome side panel**, on model `claude-opus-5`, at a reported cost of about $89.

- On 30 Sep the user said "use the skills if you want and if needed only". None were used.

**Tools used (number of calls):**

| Tool | Calls |
|---|---|
| Bash | 219 |
| Read | 88 |
| TaskCreate / TaskUpdate | 21 / 20 |
| SendUserFile | 18 |
| Firecrawl search / scrape | 15 / 10 |
| AskUserQuestion | 11 |
| Write | 4 |
| ToolSearch | 3 |
| Edit | 1 |
| SendUserMessage | 1 |

**Rendering pipeline (custom code, no video library):**

- **Rendering:** Python + **Pillow** draws every frame. Raw RGB frames are piped into **FFmpeg** and encoded as H.264. No Remotion, no headless browser.
- **Effects:** numpy grain (12 noise fields) + vignette. Scene dissolves use `Image.blend` (0.42–0.45 s, later 0.30 s). Theme colours blend across light/dark act boundaries.
- **Fonts:** TTFs pulled from npm `@expo-google-fonts/*` (Google Fonts was blocked by the proxy). Glyphs checked with fontTools.
- **Encoding:** two-pass x264 at 1,900 kbps → 27.1 MiB (to fit the 30 MiB file-send limit). Masters at CRF ~21 ≈ 129 MiB.
- **Re-renders:** partial re-renders splice a new tail at a keyframe (used for the Case 02/03 closing-card fix).
- **Long jobs:** run in the background (`setsid nohup … &`) because tool calls time out.
- **Audio:** no usable text-to-speech in the sandbox, so every video has a silent AAC track for a human VO.
- **Product screens:** stylised mock UIs, because there was no access to the real product.

**Research:** Firecrawl against primary sources (gov.uk, legislation.gov.uk, smallbusinesscommissioner.gov.uk, legalservicesboard.org.uk, plus legal-branding colour research for the palettes). A £8.9bn "unused software" figure was rejected because it came from a marketing agency.
